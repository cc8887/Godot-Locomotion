# Kimodo 导出 Pipeline 的原点对照契约

适用入口：`tools/motion-viewer` 的单栏、A/B 和多阶段链路视口。工具对源文件只读，不改变生成结果、活动包配置或 ALS 运行时。

## 空间与视角

- 共同原点是源资产坐标 `(0,0,0)`，用白色地面十字标记。不得按当前骨盆、首帧骨盆、包围盒中心或运动轨迹中心归零。
- 当前 Pipeline BVH/FBX 使用 cm；FBX 声明 UnitScaleFactor=1。Z-up FBX 仅绕固定原点做 -90° X 显示转换，Y-up SOMA BVH 保持直立。内部渲染坐标为 Y-up，水平距离使用 XZ；导出记录同时注明源 up 与显示约定。原始朝向诊断模式不应与 Z-up 正常视图混在一份对照中。
- 所有视口使用共同正交相机、相同厘米比例尺；相机固定位置 `(400,250,450)`、目标 `(0,90,0)`、垂直范围 800 cm。只在显式交互时改变视角；旋转/缩放同步应用全部视口，禁止平移至人物中心。重置相机恢复共同预设，加载资产不得自动构图。
- 不对不同骨架的体型或原始朝向做隐式缩放/朝向拟合。展示差异保留，超出视野时由用户统一缩小视图，不能独立缩放某一栏。

## 观察内容

root（橙色）与 pelvis/Hips（粉色）分别显示完整轨迹，采样包含源关键时间、60 Hz 子帧及首尾；root 绑定别名 `__viewer_root__` 保留 root 标记与轨迹语义。根运动不被预览提取或消费。

实时分别报告 root 到原点、pelvis 到原点、pelvis 到 root 的水平距离。绝对距离揭示整段存在的水平常量；只检查 `max-min` 不能发现这种问题。超过 50 cm 显示红色观察提示，**不是通用资产通过/失败门禁**：Kimodo 未转原地的源动作允许整体行进，正式 ALS 质量验收仍依据生产策略及已有门禁。

链路/A-B 同步使用归一化时间；从属栏先求值再渲染对应时间，不在已渲染后写入时间。该同步只用于粗略时间对照，不保证接触、同步 marker、停止采样帧或支撑相位对齐。

## 来源与报告

最终栏从普通 Demo 的 `assets/config/als_resource_pack.json` 解析实际 `assetRoot`；raw 文本目录解析实际 `rawRoot`。无配置时展示原版，错误指针报错，不回退到旧 Kimodo 目录。接口记录活动 resource-pack 路径与字节 SHA-256。

“导出原点对照”记录文件路径、阶段、当前求值时间、时长、源 up、显示约定、root/pelvis 渲染坐标、三种水平距离及真实相机状态。其观测对象是对应 BVH/FBX 的独立播放，不是普通 Godot 最终蒙皮/脚锁/混合图。

生成源视图读取 `artifacts/kimodo_viewer/current.json` 的明确批次注册表。批次索引含源 NPZ、rig、节点 identity 与检查状态，导出前验证回执摘要，服务器验证索引摘要；列表及链路索引使用同一批次 ID。刷新和切换批次清空旧姿态及信息，加载期间禁止切换目录；未知或损坏批次报错，禁止回退到历史同名资源。

原生源动作预览保留所有局部旋转、根平移和原始采样时间，Y-up、米转厘米，不重采样、去偏移或隐式转朝向。77 个源关节之外的静止 Root 包装节点只辅助显示；`displayRootOnly=true` 表明它不代表已分解/烘焙的资产 root。源检查通过只描述该次作者检查，所有源预览标记 `productionReady=false`；不代表目标重定向或普通 Demo 验收。

同名关联仅证明名字对应；旧 `als_regen` 中间资产没有活动生产包的哈希依赖证明，不得据此断言它是活动包的真正上游。源节点回执已接入，但完整源到目标资产链路的 provenance 仍独立开放。

## 批次与阶段链路

链路的“当前批次”只使用该批索引中的生成/周期母动作/重定向 raw/Root 分解/原地 raw/最终 FBX。历史同名中间目录禁止作为缺失阶段的替代；活动包与原版另外标注独立对照。跨批次模式明确选择两个批次和同一生产阶段，缺失阶段仍留空。切换模式/批次重建列、清空旧姿态，保持所选资产与共同相机，首帧暂停，按实际已有制品选择同步主栏。

目标包登记验证重定向输入 raw 的作业哈希、ownership 回执、authored/runtime raw 的包字节哈希及语义摘要。只有原生回读完成的目标包才登记最终 FBX，按包文件摘要核对。完整局部平移/旋转/缩放由 raw 转成只读预览，保留 Z-up、cm、原始采样时域与真实 root；不得在 Viewer 内重新分解或将轨迹从 pelvis 移走。概要的整段最大 root→原点及 pelvis→root 距离与源 FK 同步生成，便于区分起点常量、整体轨迹和自然残差。

源批次与目标包各自独立登记；没有同一生产回执时，不能按同名或时间推断它们属于同一批。失败生成候选无目标阶段是预期的阻断结果。`publish stage/finalize-fbx` 的可见性导出失败独立留证据，不影响原生产门禁或偷偷激活资源。
