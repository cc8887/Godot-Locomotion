# Flail 驱动、重力与真实场景接触

物理整链回放新增 `--flail-drive`，仅允许 scene-world chains 模式。两模型各自持有独立 Flail 动画 owner，按真实 pelvis 速度更新动画和驱动强度，再调用 `StepAnimatedScene`。此独立 owner 仅用于接触验收；普通角色未来必须复用已经存在的共享动画 owner，不能再启动第二套时钟。

`AlsFlailPhysicsRuntime` 先准备/求值并验证动画候选，再执行物理场景步，成功后提交动画时钟。场景步异常则 Cancel 动画候选；原始 authored 帧用于电机，创建修正 connector 用于物理。报告新增 flail_drive、各 rig 步数和最终动画时间，仍明确 ordinary_ragdoll_connected=false。

## 十秒回放结果

使用现有普通场景地面、重力、完整接触、睡眠判据与全部原验收门槛，没有放宽速度/限位/睡眠要求。日志目录 `artifacts/flail-scene-contact-20260923/`。

120Hz 的最终 Flail 时间分别0.25084913/0.25215143秒，真实骨盆速度趋零后源时钟趋于停住。成功报告 `report-120.json`；30/60失败仅日志、未伪造成功报告。

不带 Flail 的60Hz同场景基线独立复跑通过：末秒V/W为0、两模型睡眠，见 `baseline-60.json`。说明本批60Hz失败与新增动画驱动路径相关，不能归为原有静态目标30Hz失败，亦未定位为某一公式错误。原静态目标全矩阵最新仍9/12；新Flail模式当前只测三项，1/3通过，不能混用统计。

最终 Optimize 构建通过、零警告/错误。首次测试后调整初始化登记顺序，避免 Flail 构造失败时已登记的身体被重复释放，最终构建验证；未改数值路径。没有新 UE 导出/完整动画物理原生轨迹，不能声明驱动轨迹与UE等价。无新Core/Import全量。
