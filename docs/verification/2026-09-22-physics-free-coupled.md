# 完整自由关节连接下的共同求解对照

本批主目录 main 补齐逐阶段测试工具对 ConnectivityOnly 关节的支持，并从当前真实 30 Hz 普通落地获取新原生参考。未修改 Core 求解公式、Godot 生产逻辑、UE 插件源码或验收阈值。

## 覆盖

两套模型分别捕获第 0、1、2、6、7、8、12、13、14、15、16 帧，共22个样本。每个样本包含各自完整20/18条关节，其中恰好一条全自由无驱动连接。重放时仍保留连接身份，仅跳过无求解行的缓存、位置/速度求解及投影。原生参考由现有 Chaos 共同求解容器独立产生，不读取捕获中的 Core 输出作为答案。

前六帧采样点只有角色自身接触，不能称为落地接触。补采的第12–16帧十个样本确实包含环境接触，测试显式检查覆盖数量。总计528个位置接触/关节、隐式速度、速度接触/关节、投影及修正阶段；55个动态接触对使用不同图层级的 shock propagation。

新参考 `assets/config/v4_physics_free_coupled_reference.json` 为27,255,362字节。最终冷重复导出退出0、逐字节相同，SHA256 `A6AAC7626F1C0AF91ED539A93F49EF6D0922946A5195007854383668F3D70892`。初始12样本版本和所有日志保留于 `artifacts/physics-free-coupled-20260922/`，没有覆盖最终验证日志。

## 边界与下一步

该结果支持当前自由关节不产生求解行的处理与原生一致，并覆盖落地时共同求解；输入仍使用捕获的Gather后接触行、关节顺序、层级和预测状态，不能据此证明碰撞发现、历史、积分、原生图排序或整个世界轨迹正确。
