# Lyra animation comparison: UE 5.9 source audit

Date: 2026-09-29. This is a read-only audit of `D:\UnrealEngine\Samples\Games\Lyra` and `D:\UnrealEngine\Engine`. `Engine/Build/Build.version` reports 5.9.0. The local Lyra sample has `Source/`, `Config/`, and `Plugins/`, but no `Content/` and no `.uasset` files under its plugins. No Unreal Editor session, asset export, or runtime test was performed. Epic's online Lyra animation page currently presents 5.8 documentation, so it is supporting documentation rather than proof of the local 5.9 animation graphs.

| Topic | Direct local source evidence | Boundary for the comparison |
| --- | --- | --- |
| Distance Matching | `Engine/Plugins/Animation/AnimationLocomotionLibrary/Source/Runtime/Private/AnimDistanceMatchingLibrary.cpp:33-78` performs a binary search and interpolation on an increasing distance curve. `:214-229` negates the remaining distance and sets the Sequence Evaluator explicit time. `:155-200` provides a separate distance-traveled advance with effective play-rate clamping. | No call to these functions appears in Lyra C++; the missing Stop AnimBP prevents proving which operation Lyra uses. The old demo now names the engine-node model rather than a Lyra original implementation. |
| Foot lock | `Engine/Plugins/Animation/AnimationWarping/Source/Runtime/Private/BoneControllers/AnimNode_FootPlacement.cpp:601-667` includes planted/unplanted/replanted decisions; `:706-724` gates locking. | This is an engine node, not evidence that the Lyra AnimBP uses it. No Lyra C++ FootLock reference or AnimBP asset is present. The right-hand demo remains an explicitly generic, unconstrained input pose. |
| Turn in place | `Samples/Games/Lyra/Source/LyraGame/Character/LyraCharacter.cpp:56-76` disables orient-to-movement and enables controller yaw. `Engine/Source/Runtime/AnimGraphRuntime/Private/AnimNodes/AnimNode_RotateRootBone.cpp:32-78` applies a supplied yaw to root bone rotation. | The Root Yaw Offset modes, Turn Yaw curve, waiting logic, and per-weapon transitions are documented by Epic but live in unavailable AnimBPs. The demo's smooth yaw release is illustrative, not the original curve. |
| Mantle | `Samples/Games/Lyra/Source/LyraGame/AbilitySystem/Abilities/LyraGameplayAbility_Jump.cpp:49-68` contains Jump/StopJumping calls. No mantle/vault/climb/ledge implementation was found in the local Lyra C++ source. | Absence in C++ does not establish absence in Blueprint content. The right-hand scene is a documented jump/fall reference, not a Lyra Mantle comparison. |
| Cross-step | `Engine/Plugins/Animation/AnimationWarping/Source/Runtime/Private/BoneControllers/AnimNode_OrientationWarping.cpp:605-669` rotates the root, counter-rotates spine bones, and adjusts IK foot bones. Epic's Lyra page says it uses four cardinal strafe assets and Orientation Warping during starts. | Neither the node's existence nor its use during starts proves that Lyra uses it for reverse-direction foot crossing. The right-hand scene has been relabeled as a start-direction reference. |
| Equipment animation | `Samples/Games/Lyra/Source/LyraGame/Equipment/LyraQuickBarComponent.cpp:135-145` unequips then equips the selected slot. `LyraEquipmentManagerComponent.cpp:68-103` creates the instance and spawns actors; `LyraEquipmentInstance.cpp:69-88` attaches actors to the mesh/socket. `Weapons/LyraWeaponInstance.cpp:78-82` chooses equipped/unequipped animation-layer sets, while `Cosmetics/LyraCosmeticAnimationTypes.cpp:10-21` chooses the first rule matching all cosmetic tags, else the default. | `PickBestAnimLayer` is BlueprintCallable, but no local Lyra C++ call to `LinkAnimClassLayers` exists. Epic documents the weapon child AnimBPs and linked layers; their actual call graph and asset values cannot be checked without Lyra Content. |

The engine node and Lyra project source are different evidence levels. The revised web demos distinguish a verified engine operation, Epic's published Lyra blueprint description, and a generic teaching reference. This audit does not establish pixel- or bone-level equivalence to Lyra's animations.
