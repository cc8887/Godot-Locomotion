# 2026-10-11 Kimodo 跑步补缺

本批补充六个非道具 Run 循环／十二个身份，基底为既有 `als_nonprop_20261010_derived_v2` 的 155 个交付。在主目录保留已有修改，未提交、推送或切换默认。生产入口和稳定算法见[跑步生产合同](../architecture/kimodo-run-pipeline.md)。

## 源生成与失败

v1／v2 使用本地 RP v1.1、30 FPS、100 steps，seed 分别为 20261011／20261012，四条独立母动作各真实生成一次，共 **8 次 diffusion**。前进、后退、左前、左后都使用原版投影作为条件参考；站姿复用明确已有生成 receipt。右侧仅允许从通过门禁的左侧派生。

两个初始完整管线均因全部源循环失败而保留 `source-quality`／零交付拒绝。不会用旧资源的回读和游戏启动冒充本批源验证。v1 的周期／接触参数和稳定膝部／上身拟合探索各 96 个有界组合均拒绝，原失败目录和日志保留。

v2 的 93 个有界接触计划延长组合中，后退跑步选中第二周期、二阶拟合、四帧过渡、接触计划两側各延长一帧。其实际源作者检查通过：最大脚锚校正 **7.840 cm**、髋部降低 **0**、最大周期旋转拟合 **14.945 度**；21 帧原生时间域与严格近地滑移／周期接缝阈值保持。前进、左前与左后仍失败，右侧依赖阻断。

v3 用明确 v2 生成 receipt 重做修复和交付，新增 diffusion 为零；完成后退语义的 `A_Als_Run_Backward`／`ALS_N_Run_B` 两个身份。与基底组成 157 个交付的独立诊断包，缺口为 26 身份／14 语义，其中跑步还缺五个语义。

## 目标修复与回归

v3 的首次目标后退检查失败：原版采用脚趾支撑，但既有 target IK 只支持平脚，新动作 ball 足底仍浮高约 3 cm，没有合格支撑窗口。新增脚趾低速／竖直相位与球部世界锚定；保留脚部旋转，仅在脚跟将穿地时做有界最小俯仰校正，不把前脚掌动作改成全程平脚。

两份真实后退目标在受控修复对照中均通过原严格门禁：最大脚部调整 **2.778 cm**、骨盆降低 **0**、足部俯仰校正 **9.432 度**。原 8 cm／5 cm 位移限额保持，新增俯仰修复上限 20 度。结果保存为 `artifacts/kimodo_als/run-20261011-v3/forefoot-audit.json`；它不是最终 FBX 或游戏验证。

首次扩大回归暴露同期新增 V4 蹲走原生对照使用 Refactored skeleton 的测试夹具错误；改为使用每个原始输入自带 skeleton，原断言保持。实际各原生身份在各自骨架上通过；旧失败日志保留。包含入口拒绝无门禁 profile 的最终相关回归 **98/98** 通过，日志为 `artifacts/kimodo_als/run-20261011-v4/tests-final.log`。

最终默认 profile 核对发现成功的接触修复参数误放到前进分支；实际 v3／v4 批次规则正确，资源不受影响。已将默认后退分支与真实通过规则逐字段核对，生产图确认 cycle=1、harmonics=2、ramp=4、padding=1；修正后再跑 **98/98**，独立日志为 `tests-after-default-profile.log`。

## 完整交付状态

v3 已完成 157 个重定向及最终 FBX 全键回读，Godot 优化构建、导入、P2B 和六域请求绑定通过。该首次包仍保留两个后退目标失败。Air 十一个场景均通过，但构建 v4 改变了其冻结核对的三份 DLL，`inputsUnchanged=false`，该次整体失败保留，不能作为保持检查通过。

修复后的独立最终包为 `assets/generated/als_nonprop_20261011_run_v4/resource-pack.json`。复用已验证的 v3 作者输入完成目标转换，不新增 diffusion；157 个最终 FBX 全物理键回读和 16 个目标步态通过，失败目标清单为空。Godot 优化构建／导入／P2B／六域绑定通过；六个相关普通／站蹲／方向场景 **6/6** 通过，112 张 GPU 截图身份及单线程、并行、GPU 三模式各 28 段方向的原版足底对照通过。其余五个 Run 方向仍使用原版回退，该通过范围不表示六方向都已生成。因包仍缺 26 个身份且只选相关场景，完整 E2E 返回非零，不能升级为全量通过。

独立载荷审计核对 **1,727** 个文件摘要及保留的 **155** 个 runtime raw，均与包摘要／基底逐字节一致；默认指针保持 Land v4。证据为 `artifacts/kimodo_als/run-20261011-v4/delivery-audit.json`。

v4 Mantle 静态 **9/11**，冻结输入不变。`low-60-parallel-on` 蒙皮穿台 **4.843 cm** 且支撑手高度变化超原版 +1 cm；`rendered-low-original` 蒙皮穿台 **2.315 cm**，原 2 cm 门槛保持。高度／移动／取消／销毁十个正常案例均通过；关闭手锁负对照蒙皮穿台 **4.717 cm** 被拒绝，该矩阵整体仍返回失败，冻结输入亦不变。两类失败与基底既有开放范围一致，未更改 Mantle 资产。
