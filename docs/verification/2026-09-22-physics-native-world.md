# 完整原生世界基线与自由关节图连接

本批直接在 `D:/GodotALS` 的 `main` 实施。普通 demo 未接入实验 Core 物理；本批不是 Ragdoll/Get-up/Pose Recovery 完成证明。

## 发现与修复

此前实验整链只保留有求解行的关节，漏掉两套资产各一条 root→pelvis 全自由、无驱动关节，合计只有 36 条连接。UE `PBDJointConstraints.cpp` 的 `ShouldBeInGraph` 不因为六轴自由而排除启用的动态连接。此连接不产生约束力，却参与图支持层级和顺序。

新增 `ConnectivityOnly`：保留连接身份和图边，跳过行缓存、位置/速度求解和投影；禁止携带会被丢弃的求解设置。Import 仅对六轴自由且所有驱动关闭的关节生成这种连接，其他输入仍走原有严格编译。实验场景现在保留完整 38 条关节。测试覆盖图层级、无力/无投影、无约束轨迹逐位相同及带驱动输入拒绝。

## 独立 UE 基线

新增 `--capture-setup=<现存绝对目录>`，捕获真实初始 actor 姿态、速度、动态性及场景 13 个静态盒体。仅支持固定场景落地，不支持平台运动。输出采用新文件，拒绝覆盖。

原生命令行 `-PhysicsWorldInputs=<目录> -PhysicsWorldOutput=<新文件>` 建立独立同步 Chaos 世界，加载完整原生 PhysicsAsset，恢复捕获初态并重建场景，运行十秒。逐帧保存身体、睡眠、接触对、关节数和惯量等观察值；Core 轨迹和预期睡眠状态不驱动原生模拟。

| 原生场景 | AnimMan 入睡帧 / 保持帧 | Mannequin 入睡帧 / 保持帧 |
| --- | --- | --- |
| 普通 60 Hz | 231 / 370 | 471 / 130 |
| 高速 120 Hz | 479 / 722 | 633 / 568 |

四组末秒线/角速度均为零，均保持至少一秒休眠。两套资产各有 20/18 个线性关节，非线性关节为零。参考 `assets/config/v4_physics_world_reference.json` 为 69,725,460 字节；冷重导 SHA256 同为 `FF0C73381999BC68533A43895DB03968343CC4E826E944464C0728BB0DBAEEAF`。

边界：初始位置和线速度精确相同，但原生 particle 四元数为 float，最大分量差 2.9426034497959108e-8；conditioned inverse inertia 最大向量差 4.896755583719634e-8。原生时间步使用 `1.f/Hz`，Core 当前使用 double 时间步。没有宣称整条轨迹等价，也没有用这些微差推定剩余失败的原因。环境材质沿用本诊断的统一材质约定；没有覆盖运动平台原生基线。
