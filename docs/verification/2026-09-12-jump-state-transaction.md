## 本批实现

`AlsJumpStateCompiler` 核对原生编译节点库存，绑定 Jump 状态机 263、父级
Main Movement 245，以及六个独立序列节点。没有重新导出或修改 UE 资产/插件。

`AlsJumpStateRuntime` 按共享状态机的初始化日志收集来源。双路起跳初始化
Walk/Run 两个播放器，Update 只访问实际相关子节点；左右脚各自的速度插值
历史保留在候选帧，根初始化只进入 Entry，未访问的另一只脚历史不被清空。
来源更新携带父/子状态祖先链、活动标记、root-motion 权重及惯性化请求上下文。
回调失败不会让运行器永久处于重入保护状态；可从原已提交帧重试。

`AlsJumpSourceCollector` 从正式来源数据取得初始时间、时长、倍率和同步身份。
Initialize 推进候选 epoch，清理候选缓存权重；Update 收集贡献，不单独推进时钟。
真实来源时间由现有共享 Sync batch 一次推进，正式 P5 来源映射产生通知 tick，
再准备来源事件候选。状态、输入、来源、骨骼和事件只有在外层接受候选时提交。

GetRelevantAnimTimeRemaining 对照既有本地 UE 原生实现：按 baked 顺序选择
严格大于当前最佳缓存权重的播放器，相等保留第一个；无相关播放器返回 MAX_flt。
正向为 Length−Time，反向为 Time；方向由播放器上次 Update 捕获的速率决定，
不能提前使用本帧尚未更新到该节点的全局输入，也不能把剩余时间除以播放倍率。

状态机修复：同帧进入 Jump Left/Right 或 Land 后，SetState 已清除目标播放器
缓存权重，后续完成规则必须看到无相关资产。否则旧的“已播完”值会让重新起跳
直接跳到 Flail，或让刚进入的 Land 立刻结束。新增测试同时覆盖两只脚和 Land。

共享帧容量扩为 62 个播放器/88 个样本，容纳 Grounded+Jump。默认地面绑定仍
为 56/82；姿势消费者按实际绑定数量分配/截取时间数组，容量不等于有效来源数。
本批的 Jump 回放通过正式编译器生成完整 P5 来源、库存和事件 occurrence 绑定。
