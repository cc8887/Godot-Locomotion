# Mantle 交付资源适用性复核

当前生成 Mantle 对默认女角色尚不具备生产交付资格。对原版、生成转换、接触修复、最终 raw／FBX 和已保存运行轨迹的复核发现两个叠加问题：生产转换没有重建目标骨架的实体 twist 运动，女角色运行接触适配又将支撑臂推到完全伸直。[上一轮诊断](2026-10-12-mantle-high-wrist-twist-diagnosis.md)定位了后者，但不能据此将变形主要归于运行时，或将交付资源视为已经合格。

这一结论限定当前 Mantle 和目标角色；尚未证明所有动作不可用，也不能由 SOMA 没有 ALS twist 节点就判定原始 diffusion 姿态需要丢弃。优先补生产转换与目标形变验收，再依据完整姿态对照决定是否重新生成源动作。

## 生产侧明确缺口

SOMA77 的当前生成 NPZ 没有 ALS 实体 twist 节点。独立 Pipeline 的 [`offline_retarget.mapping`](../../../Kimodo-Pipeline/tools/kimodo_pipeline/offline_retarget.py) 映射了上臂／前臂／手，未映射 twist。`convert` 对未映射骨使用：

```python
world[:, i] = world[:, parent] @ aligned[parent].T @ aligned[i]
```

相对父骨的局部旋转由此恒定为参考姿态；仅跟随父骨的全局运动不能替代目标骨架的扭转分配。这个行为从目标手臂修复之前就存在，经过目标支撑 IK、指节蒙皮修复、Root/Pelvis 分解仍未补齐，最终 FBX 四根手臂 twist 的局部参考角差峰值均小于 `2.1e-14°`。

原版 High 左前臂 twist 在支撑窗口的局部参考角差峰值约 75.28°、左上臂约 38.85°；生成目标对应均接近零。这里是 twist 骨自身的局部旋转变化，不等于腕关节的纯轴向角度；原版曲线用于识别目标骨运动需求，不能原样复制到不同的生成肢体姿态。

## 运行适配新增的问题

生成交付片段在整个左手支撑窗口的最小肘弯约 58.67°，并没有完全伸直。因此女角色实际约 0° 肘弯不能归为片段原始姿态。保留比例映射按全臂长可达球移身体，并强制掌向匹配，缺少肘弯余量及肩／身体姿态联动；该问题仍需修复。

保存的 1.5 m tick 113 驱动人偶肘弯约 93.41°，女角色约 0°，腕部局部姿态差约 42.29°。该帧驱动手端点的请求修正约 22.43 cm；它大于生产名义目标修复预算，来自高度／身体组成姿态和运行锚点适配，不能冒充生产端的小幅修正结果。目标资产与实际障碍／目标比例联合验收尚不完整。

## 为什么既有门禁仍通过

源作者和目标质量报告均为通过。当前作者／目标检查覆盖手端点位置、朝向和漂移、骨盆轨迹、落地脚、骨长／单位缩放与有界指节修复；High 左手目标修正最大约 9.83 cm，接近既有 10 cm 预算。预算通过只限制修正幅度，不能证明完整支撑姿态自然。

FBX 回读证明文件忠实保存了生成 raw；它也会忠实保存恒定的 twist。运行端的贴沿／穿模检查同样不覆盖肘弯余量、腕部局部姿态、目标 twist 分配和连续接缝形变。导出正确、接触端点正确与完整角色形变合格是不同的验收项。此前局部通过没有建立最后一项。

## 更新后的处理优先级

1. 在生产目标 rig 上从生成肢体实际姿态重建 twist 分配，并复核姿态、骨轴／蒙皮和关节连续性；补门禁后重出对应资产，保持原接触、修复幅度、骨长及穿模门禁。静态动作可以没有 twist 变化，不能机械要求所有轨道非零或达到原版某个角度。
2. 修复女角色支撑适配的完全伸肘，联动肩／身体，并在运行 IK 改变前臂姿态后保持相应扭转分配；沿用原时钟与提交／回滚。
3. 用原版／生成片段、驱动／目标模型、名义／实际高度的同帧全姿态和连续 GPU 对照验收。若源身体与支撑本身仍不合理，再修改生成条件或重生成，避免仅靠增加运行修正量掩盖源问题。

该转换行为是通用策略，其他大幅前臂旋转动作也需要按同类证据复核；本轮没有全包扫描，不能推断所有动作都存在相同程度的视觉失败。没有运行新 Godot、修改 Pipeline 算法、重新生成／转换资产、改变默认选择或完成生产验收；女角色数值引用保存的诊断版本，最新 DLL 仍不在本轮运行认证范围内。

复现脚本为[只读资源审核](../../artifacts/tests/mantle-resource-suitability-20261012-v1/analyze-resource.py)，使用独立 Pipeline 的 Windows Python；写入本次诊断目录，读取并冻结对应 raw／FBX 和来源，不改变资产。
